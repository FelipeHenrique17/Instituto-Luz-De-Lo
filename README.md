
# 💛 Instituto Luz de Lô — Landing Page Institucional

Landing page desenvolvida para o Instituto Luz de Lô, uma organização sem fins lucrativos que acolhe mulheres e seus familiares durante o tratamento oncológico, promovendo ações sociais e campanhas de arrecadação.

## 📋 Sobre o Projeto

O projeto consiste no desenvolvimento de uma landing page institucional para o Instituto Luz de Lô, com o objetivo de apresentar a história da organização, divulgar suas iniciativas sociais e facilitar a participação de pessoas interessadas em contribuir com a causa.

A nova versão do projeto traz melhorias na identidade visual, organização das informações e experiência do usuário, além de funcionalidades interativas para facilitar as doações e o cadastro de novos voluntários.

## ⚙️ Funcionalidades

- [ ] Página inicial com apresentação do instituto.
- [ ] Seção institucional com a história da ONG.
- [ ] Apresentação das ações e iniciativas sociais.
- [ ] Seção de doações e formas de contribuição.
- [ ] Seleção de valores personalizados para doação via PIX.
- [ ] Funcionalidade de copiar código PIX conforme o valor escolhido.
- [ ] Formulário para pessoas interessadas em atuar como voluntárias.
- [ ] Melhorias na interface e na experiência de navegação.
- [ ] Organização e modernização do design.
- [ ] Layout adaptado para diferentes dispositivos.

## 🛠️ Tecnologias Utilizadas

As principais tecnologias utilizadas no desenvolvimento foram:

- **Linguagem:** JavaScript
- **Frontend:** HTML e CSS
